# 📊 AI-Enhanced HR Analytics Dashboard | Power BI + Gemini AI

### Interactive Workforce Analytics with a Generative AI-Powered HR Assistant

An end-to-end HR Analytics portfolio project combining **Microsoft Power BI** for interactive data visualization with **Google Gemini AI**, **Python**, and **Streamlit** for conversational HR analytics.

The project helps users explore employee demographics, workforce distribution, attrition trends, and key HR metrics through interactive dashboards and an AI-powered assistant.

## 🖥️ Dashboard Preview

![HR Analytics Dashboard](Dashboard_Preview.png)

## 🚀 Project Overview

This project consists of two connected components:

**1. Power BI HR Analytics Dashboard**

An interactive Power BI dashboard that visualizes workforce KPIs, employee attrition, departmental performance, salary distributions, and employee demographics.

**2. AI-Powered HR Assistant**

A conversational AI assistant developed using Python, Streamlit, and Google's Gemini AI.

The Power BI dashboard includes an **Ask HR AI** button that opens the deployed Streamlit assistant in a separate browser tab, allowing users to ask natural-language questions about HR data.

## 📈 Dashboard KPIs

The Power BI dashboard tracks six primary HR metrics:

1. Total Employees
2. Active Employees
3. Attrition Count
4. Attrition Rate (%)
5. Average Employee Age
6. Average Employee Experience

All metrics respond to the relevant dashboard filters.

## 🔗 AI Chatbot Integration

The dashboard provides an **Ask HR AI** button that launches the Streamlit-based AI assistant in a separate browser tab.

## ▶️ How to Use

1. Download the `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Explore the HR analytics visuals using the interactive filters.
4. Click the **Ask HR AI** button.
5. The Streamlit AI assistant opens in your browser.
6. Ask questions about HR data to generate AI-powered insights.
